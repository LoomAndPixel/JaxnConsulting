# Jaxn Consulting brand files

Everything made for the Jaxn Consulting brand, exported from the design canvas. This folder is kept
with the theme for safekeeping, but it is **not part of the website**: it's left out of the theme zip
that gets uploaded to WordPress.

| Folder | What's in it | Use it for |
|---|---|---|
| `logo/` | The logo ("Jaxn.") and the "J." monogram. SVG (sharp at any size) and 2400px PNG with a transparent background. `-reverse` and `-mono-white` are for dark backgrounds. | Documents, slides, partner sites, anywhere a logo is needed |
| `guide/` | The three brand-guide sheets: logo system, color / type / voice, image style | Reference for anyone designing something for Jaxn |
| `social/` | Profile picture, LinkedIn / Facebook / X / Google Business banners, three post templates, and the website link-preview card, each at the exact size the platform asks for | Upload directly to each platform |
| `print/` | Business card front and back (3.5 × 2 in) and the letterhead (US Letter), as print-ready PDFs and 300 dpi PNGs | Send the PDFs to a printer |
| `email/` | The email signature, at 2× for sharp display | Add as an image in Outlook / Gmail signature settings, linked to jaxnconsulting.com |
| `video/` | Video-call background, 1920 × 1080 | Zoom / Teams background |
| `website/` | The drawings made for the website (dashboard, project illustrations, "How it works" diagrams, Memphis map). The same files are in the WordPress media library. The diagrams are also included as SVG. | Reuse in proposals and case-study decks |

Brand basics (full detail in `guide/`):

- **Colors:** Jaxn Green #1F4D3B, Paper #F4EFE6, Ink #1C211E, Sand #EAE3D6, Rust #A8492A (the logo's
  dot on light backgrounds), Coral #E9A27F (the dot on dark backgrounds).
- **Fonts:** Fraunces for headings, Instrument Sans for text. Both are free (SIL Open Font License);
  the web versions are in `../assets/fonts/`.
- **Contact details:** info@JaxnConsulting.com · (425) 283-7378 · JaxnConsulting.com. Write the
  email and web address in CamelCase like this in anything people read.

The letterhead's `[Date]` and `[Recipient name and address]` are meant to be filled in per letter.
